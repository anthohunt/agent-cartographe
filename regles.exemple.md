# Règles sur les machines (exemple ; les vraies règles de l'installation sont dans etat/regles.local.md, hors dépôt)
- Serveur = tour de contrôle : sessions de pilotage et services en ligne seulement, aucun agent de travail.
- Tour : réservée à un usage précis ; elle n'est jamais rallumée pour autre chose.
- Portable : trois agents au maximum.
- Postes prêtés : leur propriétaire d'abord ; un travail perso y tourne sans laisser de trace (copie effacée et vérifiée).
- Chaque session ou agent visible porte un nom au format « Projet › travail (machine) ».
